This document covers the configuration of PostgreSQL database and Redis cache services within the discourse_docker deployment system. It explains how these services are configured through templates, integrated with the container orchestration system, and optimized for Discourse forum performance.

For web application configuration, see Web Services Configuration. For SSL/TLS security configuration, see SSL/TLS and Security.

Overview

The discourse_docker system provides PostgreSQL database and Redis cache services through a modular template system. These services can be deployed together in a standalone configuration or separately in distributed setups.

Sources: launcher92-98 templates/postgres.template.yml1-285 templates/redis.template.yml1-95
